# Social Assistance Exam Lab

A responsive, Traditional Chinese exam-practice website based on the uploaded course PDF **「單元8 社會救助政策與法規」**.

## Features
- Topic-based practice: poverty concepts, Children's Future Education and Development Account, low-/middle-low-income eligibility, Social Assistance Act.
- Nightmare Mode for higher-difficulty law and case-application questions.
- Immediate marking with explanations and slide/page references.
- Progress, accuracy and incorrect-answer review stored locally in the browser.
- Responsive layout for mobile, tablet and desktop.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Deploy with GitHub Pages
1. Open repository Settings → Pages.
2. Select **Deploy from a branch**.
3. Choose `main` and `/(root)`, then Save.
4. Wait for GitHub Pages to publish the site.

## Source and scope
Questions are authored from the user-provided lecture PDF and cite its page numbers. They are practice questions, not represented as official examination questions. Some thresholds and amounts in the lecture are year-specific; check current official rules before relying on them outside exam practice.
